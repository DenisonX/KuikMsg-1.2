# KuikMsg 1.2

Extensão Chrome/Edge Manifest V3 para apoio ao atendimento no Digisac.

## Recursos

- Mensagens rápidas no `https://tek.digisac.app/*`
- Adicionar, editar e excluir mensagens
- Busca de mensagens ignorando acentos e maiúsculas/minúsculas
- Restaurar mensagens padrão
- Tema claro/escuro azul
- Salvar conversa atual em `.txt`
- Log automático local de conversas
- Exportar e limpar logs
- Popup com atalhos da extensão
- Homepage interna com tutorial e instruções

## Instalação local

1. Abra `chrome://extensions` ou `edge://extensions`.
2. Ative o **Modo do desenvolvedor**.
3. Clique em **Carregar sem compactação**.
4. Selecione a pasta `1.2`.
5. Abra o Digisac e use o botão flutuante do KuikMsg.

## Observação

Este repositório publica a versão `1.2` em desenvolvimento. Backups, versões antigas e arquivos compactados não são versionados.
